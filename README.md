# АРХИВ — Telegram Mini App

Это отдельный **публичный** репозиторий только для статического сайта «АРХИВ».
Исходный Python-бот, `.env`, токены администратора и SQLite сюда загружать нельзя.

## Как опубликовать сайт

1. Скачайте `ARHIV_8_6_GITHUB_PAGES_READY.zip` из ChatGPT.
2. В этом репозитории выберите **Add file → Upload files** и загрузите **только ZIP**, не распаковывая его.
3. Нажмите **Commit changes** в ветке `main`.
4. В GitHub откройте **Settings → Pages** и в поле **Source** установите **GitHub Actions**.
5. На вкладке **Actions** следите за workflow **Deploy Archive Mini App**; в случае необходимости нажмите **Run workflow**.

GitHub Actions автоматически извлечёт `index.html`, `data/stories.json`, все фотографии и GIF в опубликованный сайт.

**Адрес после успешной публикации:** https://hah18905-lab.github.io/archive-mini-app/

Для запуска в Telegram: @BotFather → /setmenubutton → выбрать бота → вставить HTTPS-адрес сайта.

### Ограничения
GitHub Pages размещает только статический сайт. Бот на Python не запускается здесь; оценки и рекомендации сохраняются в браузере читателя и не синхронизируются между устройствами. Не публикуйте секретные материалы, личные данные и админские файлы.
